## Featured Projects

### 🔐 [FPGA RSA Shared-Factor Detector](https://github.com/esh2900/fpga-rsa-shared-factor-detector)

FPGA accelerator based on parameterizable VHDL GCD cores for detecting
shared prime factors between RSA public keys.

The project explores:

- Stein's Binary GCD algorithm
- Parameterizable RTL architectures
- Wide-integer arithmetic
- FPGA parallelism
- Hardware acceleration
- Self-checking VHDL verification

---

### ⚙️ [FPGA Digital Design in VHDL](https://github.com/esh2900/VHDL_basics_vivado)

Collection of FPGA and RTL design projects developed in VHDL.

Current implementations include:

- UART TX/RX
- UART loopback verification
- Synchronous FIFO buffer
- Finite State Machines
- Carry Lookahead and Ripple Carry Adders
- FPGA synthesis and timing comparison
- Self-checking VHDL testbenches

---

### 🚀 [Spacecraft Sensor Simulation & FDIR](https://github.com/esh2900/spacecraft-sensor-fdir)

A multithreaded spacecraft sensor simulation developed in **C++20**, featuring sensor acquisition, real-time-oriented data processing, and Fault Detection, Isolation, and Recovery (FDIR) monitoring.

The project includes:

- Multithreaded sensor acquisition (IMU and GNSS)
- Thread-safe communication using mutexes and shared queues
- Periodic data processing and sensor data validation
- Independent FDIR monitoring and watchdog mechanisms
- Fault injection and failure simulation
- Unit testing, CSV logging, and Python-based data visualization
